# Garabato 3D Inclusivo

Versión de Garabato 3D pensada para chicos y chicas ciegos o con baja visión.

- **Voz**: cada acción se anuncia en voz alta (español).
- **Vibración**: confirma acciones y bordes (solo Android; iPhone/iPad no vibran).
- **Editar sin ver**: botones grandes para agregar, elegir, mover, agrandar, girar, hacer hueco y borrar figuras.
- **Explorar con el dedo**: vibra y dice qué figura tocás.

Se usa abriendo `index.html` (o con GitHub Pages: Settings → Pages → rama main).
